# Рядом — Асбест (прототип PWA)

Адаптивный прототип городского приложения: афиша, карта и каталог организаций. Включает демонстрационную панель добавления записей, PWA manifest и service worker.

## Важно перед запуском
- Карточки мероприятий и организаций, включённые в прототип, являются демонстрационными примерами. Они не подтверждают реальные события, адреса или расписания Асбеста.
- Демо-панель администратора НЕ защищена: она предназначена только для локального прототипирования. Не размещайте её в публичном интернете как настоящую админку.
- Записи сохраняются в localStorage только текущего браузера и не синхронизируются между устройствами.
- Для карты и Leaflet нужен интернет. Стандартные тайлы OpenStreetMap нельзя массово загружать заранее для офлайн-карт; для этого нужен поставщик, который явно разрешает такой сценарий.

## Быстрый просмотр
PWA и service worker работают через HTTPS или localhost. Для локального запуска:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Следующий этап для production
1. Создать проект Supabase.
2. Применить `supabase-schema.sql` в SQL Editor.
3. Включить вход администратора и Row Level Security; проверять права на серверной стороне.
4. Перенести чтение и запись из localStorage в Supabase, настроить загрузку изображений.
5. Подключить домен и HTTPS, затем проверить установку на Android, iPhone и desktop.
6. Перед публикацией наполнить каталог только проверенными организациями и подтверждёнными мероприятиями.

## Технологии
- HTML/CSS/JavaScript — первый кликабельный прототип без сборщика.
- Leaflet + OpenStreetMap — интерактивная карта с атрибуцией.
- PWA manifest + service worker — основа установки и кэширования оболочки.
- Supabase — предлагаемый backend следующего этапа.
